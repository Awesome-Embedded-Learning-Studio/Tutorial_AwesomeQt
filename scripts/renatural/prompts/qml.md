## 家族定位与硬前提

- **金科玉律边界**：不摊 QML 深度。本族 7 篇是「Widgets 主线之外的一扇窗」：够读者看懂 / 改动 / 判断何时用，不开 QML 全谱系教程。写手拿到越界的旧文素材时，收进转诊链接而不是展开。
- **开口接住来路**：首篇（01-qml-syntax）开篇必须接住「您刚把 Widgets 写了七十多篇」——读者从 Widgets 世界进来，QML 的声明式思维转换是本族真正的「来路」问题。
- **Qt5→Qt6 增量**：P3 回流读者在本族最密集，凡与 Qt5 习惯有差异处给一句增量（qtquick 导入路径 / QtQuick.Controls 版本 / 信号语法），不展开迁移史。

## 基线教训直接入规（来自 `renatural/state/coldread-baseline.md` §2，01 篇是基线样本）

- **坑必须给后果现场**：全篇唯一加粗警告若只报雷名（「直接赋值会打断绑定」）不给爆炸现场，等于没写——每坑写到「断掉绑定后 UI 停在旧值、后续 state 变化不再刷新」这个可观察层面，机制不许甩给「下一篇文章」。
